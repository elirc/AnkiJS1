# Learning Rubrics

## Junior

Observable behaviors:
- Runs app/tests and reads scripts.
- Traces one UI action to one repository.
- Adds a focused test using existing style.
- Avoids unrelated refactors.

Checklist:
- [ ] I can explain capture end to end.
- [ ] I can identify synced vs local-only tables.
- [ ] I can run `npm test`.

## Mid-Level

Observable behaviors:
- Designs a cross-layer change with schema, repo, UI, and tests.
- Explains transaction boundaries and failure modes.
- Debugs by narrowing layer.
- Reviews for correctness, not just style.

Checklist:
- [ ] I can modify queue or merge behavior safely.
- [ ] I can add repository and UI tests.
- [ ] I can explain RLS and local-only adoption.

## Senior

Observable behaviors:
- Identifies architectural commitments and blast radius.
- Proposes migrations with rollback.
- Separates confirmed risks from hypotheses.
- Teaches others through anchored examples.

Checklist:
- [ ] I can critique sync reliability.
- [ ] I can plan a schema evolution.
- [ ] I can write an RFC with security/performance/test sections.
